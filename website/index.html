MDWriter 3.0 拒绝将你的思想上传至任何第三方云端。支持直接与本地端口通信，配合 MCP 扩展宿主与 7 大隐私搜索引擎，打造真正的本地 AI 工作站。 MDWriter 3.0 rejects cloud telemetry. Direct endpoint socket connection to local LLMs with built-in MCP host and privacy-first web search.

  • 支持主流本地引擎：Ollama (11434)、LM Studio (1234)、oMLX、llama.cpp、MLX、Jan 及自定义 REST/SSE 端点。Broad Local Engines — Ollama, LM Studio, oMLX, llama.cpp, MLX, Jan & Custom OpenAI endpoints.
  • 18+ Tool Calling 全量操控：AI 可直接替换选中文字、重命名文稿、设置标签、插入 Markdown 表格与代码块。18+ Tool Calling Suite — AI directly edits selection, manages notes, tags metadata, and formats tables/code.
  • MCP 插件与原生选择器：可视化预设库（文件系统、网页抓取、Puppeteer、Brave 搜索、GitHub），一键选择本地文件夹。Model Context Protocol (MCP) Host — Visual presets with native folder picker & AI automated registration.
  • 7 大隐私搜索引擎：DuckDuckGo (内置免 Key)、SearXNG、Brave、Tavily、Exa、Google、Bing 实时引用。7 Web Search Engines — DuckDuckGo (zero key), SearXNG, Brave, Tavily, Exa, Google & Bing.
